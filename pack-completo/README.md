# Pack Completo — Skills Jurídicas

Conjunto de skills para Claude Code voltadas à prática jurídica brasileira.
Cada skill auxilia na elaboração e revisão de peças e documentos seguindo
boas práticas de redação forense e a legislação vigente (CPC/2015, CC/2002,
CF/1988 e legislação esparsa).

## Skills disponíveis

| Skill | Finalidade |
|-------|-----------|
| `peticao-inicial` | Elaborar petição inicial cível conforme art. 319 do CPC |
| `contestacao` | Elaborar contestação e arguir preliminares (art. 335-342 CPC) |
| `recurso` | Estruturar recursos (apelação, agravo, embargos) |
| `contrato` | Redigir e revisar contratos civis e empresariais |
| `parecer-juridico` | Produzir pareceres e consultas jurídicas fundamentadas |
| `notificacao-extrajudicial` | Redigir notificações extrajudiciais |
| `procuracao` | Gerar procurações ad judicia e ad negotia |
| `analise-caso` | Analisar caso concreto, teses, riscos e estratégia |

## Instalação

Coloque `pack-completo.zip` na mesma pasta do `instalar-skills.sh` e rode:

```bash
bash instalar-skills.sh
```

As skills serão extraídas para `~/.claude/skills/pack-completo/`.
Abra uma nova sessão do Claude Code para ativá-las.

## Aviso importante

Estas skills são ferramentas de apoio à redação. **Não substituem a revisão
de um(a) advogado(a) habilitado(a)**, nem constituem aconselhamento jurídico.
Toda peça gerada deve ser conferida quanto a fatos, datas, valores, competência
e jurisprudência atualizada antes do protocolo.
